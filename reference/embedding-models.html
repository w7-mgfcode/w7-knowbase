01

ÁttekintésOverview

Az embedding modellek szövegeket sűrű numerikus vektorokká alakítanak, amelyekben a szemantikailag hasonló szövegek közel kerülnek egymáshoz a vektortérben. RAG rendszerekben az embedding minősége közvetlenül meghatározza a visszakeresés pontosságát: gyenge embedding esetén még a legjobb reranker sem tud kármenteni. A 2026-os modellgeneráció — Qwen3-Embedding, Voyage 4, Gemini Embedding 2 — LLM-gerincű architektúrákat, Matryoshka (MRL) dimenziócsökkentést, kvantizálás-tudatos tanítást és multimodális vektortereket hoz. Embedding models convert text into dense numerical vectors where semantically similar texts cluster close together in the vector space. In RAG systems, embedding quality directly determines retrieval accuracy: even the best reranker cannot fully compensate for a weak embedding. The 2026 model generation — Qwen3-Embedding, Voyage 4, Gemini Embedding 2 — brings LLM-backbone architectures, Matryoshka (MRL) dimension reduction, quantization-aware training, and multimodal vector spaces.

Az iparági értékelési eszköz az MTEB, amelynek leaderboardja ma alapból a többnyelvű MMTEB rangsort mutatja, külön angol (MTEB eng v2) és legacy v1 fülekkel. RAG-hoz a Retrieval alkategória a meghatározó — az összesített pontszám félrevezető lehet. A dense modellek mellett terjednek a sparse (lexikai) és a ColBERT-stílusú late-interaction megközelítések is. (Adatpillanat: 2026. május.) The industry evaluation tool is MTEB, whose leaderboard now defaults to the multilingual MMTEB ranking, with separate English (MTEB eng v2) and legacy v1 tabs. For RAG the Retrieval sub-category is what matters — the aggregate score can be misleading. Alongside dense models, sparse (lexical) and ColBERT-style late-interaction approaches are also gaining ground. (Data snapshot: May 2026.)

Kontextualizált chunk-embeddingContextualized chunk embedding

Három párhuzamos megközelítés: (1) Anthropic Contextual Retrieval — LLM minden chunk elé kontextus-leírást fűz; a gyártó szerint a top-20 visszakeresési hibaarány 5.7%-ról 1.9%-ra esik. (2) Késői chunkolás (Jina) — előbb az egész dokumentum embedingje, majd felosztás és pooling, LLM-hívás nélkül. (3) voyage-context-3 — a modell tanulja be a globális dokumentum-kontextust minden chunk-vektorba; a gyártó szerint átlag +14% a szokásos chunkolási alapvonalakhoz képest. Three coexisting approaches: (1) Anthropic Contextual Retrieval — an LLM prepends a context blurb to each chunk; vendor-reported, top-20 retrieval failure drops from 5.7% to 1.9%. (2) Late chunking (Jina) — embed the whole document first, then split and pool, with no LLM call. (3) voyage-context-3 — the model is trained to inject global document context into each chunk vector; vendor-reported, ~+14% on average over standard chunking baselines.

Gyakorlati ajánlásPractical recommendation

Kezdj bi-encoderrel → ha kell, adj hozzá cross-encoder rerankelést → ColBERT-et csak akkor, ha ez még mindig nem elég. A legtöbb produkciós RAG az első lépésnél megáll. Start with a bi-encoder → add cross-encoder reranking if needed → reach for ColBERT only if that is still insufficient. Most production RAG stops at the first step.

# pip install sentence-transformers openai voyageai FlagEmbedding
# Dense embedding with MRL dimension reduction (Matryoshka)
from openai import OpenAI

client = OpenAI()

def embed_texts(texts: list[str], dimensions: int = 512) -> list[list[float]]:
    # text-embedding-3-small supports MRL: reduce from 1536d to any lower value
    response = client.embeddings.create(
        model="text-embedding-3-small",
        input=texts,
        dimensions=dimensions,   # MRL: 256 / 512 / 768 / 1536
    )
    return [item.embedding for item in response.data]

# Open-source alternative: BGE-M3 with dense + sparse modes
from FlagEmbedding import BGEM3FlagModel

model = BGEM3FlagModel("BAAI/bge-m3", use_fp16=True)

def embed_bge(texts: list[str]) -> dict:
    # Returns dense, sparse (lexical), and colbert_vecs
    return model.encode(
        texts,
        batch_size=12,
        max_length=8192,
        return_dense=True,
        return_sparse=True,
        return_colbert_vecs=False,
    )

# Instruction-tuned model: Qwen3-Embedding with an asymmetric task prefix
from sentence_transformers import SentenceTransformer

qwen = SentenceTransformer("Qwen/Qwen3-Embedding-8B", trust_remote_code=True)

query_vecs = qwen.encode(
    ["What is Matryoshka Representation Learning?"],
    prompt_name="query",          # asymmetric: query vs. passage prefix
)

import voyageai

vo = voyageai.Client()
ctx = vo.contextualized_embed(
