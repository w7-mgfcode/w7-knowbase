Flat RAG

A legegyszerűbb RAG-minta: egységes darabokra bontott korpusz, vektoros keresés, egyetlen generálási lépés. The simplest RAG pattern: a corpus split into uniform chunks, vector search, and a single generation step.

01

ÁttekintésOverview

A Flat RAG a legegyszerűbb minta: a dokumentumokat egységes méretű darabokra (chunk) bontja, vektoros beágyazásként tárolja, és egyetlen lekérdezésben a leghasonlóbb darabokat adja a generáló modellnek. Flat RAG is the simplest pattern: documents are split into uniform chunks, stored as vector embeddings, and a single query hands the most similar chunks to the generation model.

Mivel nincs többszintű logika vagy ágens, a Flat RAG gyorsan üzembe helyezhető és könnyen hibakereshető — ezért kiváló kiindulópont és összehasonlítási alap az összetettebb minták mellé. With no multi-level logic or agent, Flat RAG is fast to deploy and easy to debug — making it an excellent starting point and a baseline to compare richer patterns against.

flowchart TD
  Q[User query] --> EMB[Embedding model]
  EMB --> VS[(Vector index)]
  VS --> TOPK[Top-K chunk selection]
  TOPK --> FILT[Reranking - optional]
  FILT --> CTX[Context assembly]
  CTX --> GEN[Generation - LLM]
  GEN --> ANS[Answer with citations]
  DOC[Documents] --> CHUNK[Chunking]
  CHUNK --> CEMB[Chunk embedding]
  CEMB --> VS

A dokumentumok darabolás és embedding után kerülnek a vektoros indexbe; lekérdezéskor a Top-K legközelebbi chunk kerül a generáló modell kontextusába. Documents are chunked and embedded into the vector index; at query time the Top-K nearest chunks are passed as context to the generation model.

Mikor érdemes használniWhen to use it

ErősségekStrengths

  • Gyors prototípus-építés: a legkisebb architektúrális overhead.Rapid prototyping: the smallest architectural overhead.
  • Könnyen hibakereshető és mérhető — ideális baseline-ként.Easy to debug and benchmark — ideal as a baseline.
  • Homogén, kis korpuszon (kb. 5 000 dokumentum alatt) kiváló pontosságot ad.Excellent accuracy on homogeneous, small corpora (under ~5 000 documents).
  • Nincs szükség speciális adatbázisra — pgvector vagy Chroma elegendő.No specialized database required — pgvector or Chroma is sufficient.

KihívásokTrade-offs

  • Nagy, heterogén korpuszon a relevancia gyorsan romlik.Relevance degrades quickly on large, heterogeneous corpora.
  • Nem támogatja a több-lépéses következtetést.Does not support multi-hop reasoning.
  • Fix Top-K: nem alkalmazkodik a kérdés összetettségéhez.Fixed Top-K: does not adapt to query complexity.
  • Cross-domain zaj: nem releváns területek chunk-jai is bekerülhetnek.Cross-domain noise: chunks from irrelevant domains can contaminate results.

Pro tippPro tip

Hybrid keresés (BM25 + vektoros) és egy könnyű reranker (pl. Cohere Rerank vagy cross-encoder) hozzáadásával a Flat RAG pontossága 15–25%-kal javítható anélkül, hogy az architektúra komplexitása számottevően nőne. Adding hybrid search (BM25 + vector) and a lightweight reranker (e.g. Cohere Rerank or a cross-encoder) can improve Flat RAG accuracy by 15–25% without meaningfully increasing architectural complexity.

KódpéldaCode example

flat_rag_query.py 
# Build the vector store from documents
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings
from langchain_text_splitters import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(chunk_size=512, chunk_overlap=64)
chunks = splitter.split_documents(documents)

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
vectorstore = Chroma.from_documents(chunks, embeddings)

# Retriever with optional reranking
retriever = vectorstore.as_retriever(search_kwargs={"k": 6})

# RAG chain: retrieve → augment → generate
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.runnables import RunnablePassthrough

prompt = ChatPromptTemplate.from_template(
    "Answer using only the context below.\n\nContext:\n{context}\n\nQuestion: {question}"
)
llm = ChatOpenAI(model="gpt-4o-mini")

chain = (
    {"context": retriever, "question": RunnablePassthrough()}
    | prompt
    | llm
)
response = chain.invoke(question)
