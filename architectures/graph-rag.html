Graph RAG

01

ÁttekintésOverview

A Graph RAG túlmutat a hagyományos vektoros keresésen. Míg a klasszikus RAG dokumentumdarabokat keres szemantikai hasonlóság alapján, a Graph RAG egy strukturált tudásgráfot használ az információk összekapcsolására. Így a rendszer „átléphet” az egymástól független dokumentumok határain. Graph RAG goes beyond traditional vector search. Where classic RAG retrieves document chunks by semantic similarity, Graph RAG uses a structured knowledge graph to interconnect information — letting the system traverse the boundaries between otherwise disconnected documents.

Az architektúra különösen erős a több-lépéses következtetést igénylő kérdéseknél, például: „Hogyan hat az A projekt a B és C csapat együttműködésére?” A gráf élei mentén történő bejárás pontosabb kontextust ad a generáló modellnek. The architecture is especially strong for questions that need multi-hop reasoning, such as: “How does Project A affect collaboration between teams B and C?” Traversing the graph edges gives the generation model more accurate context.

KódpéldaCode example

graph_rag_query.py 
# Initialize the graph store
graph_store = Neo4jGraphStore(url=NEO4J_URI, username="neo4j", password=PASSWORD)

# Build the knowledge-graph index
index = KnowledgeGraphIndex.from_documents(
    documents,
    max_triplets_per_chunk=2,
    storage_context=StorageContext.from_defaults(graph_store=graph_store),
)

# Query with graph traversal
query_engine = index.as_query_engine(
    include_text=True,
    response_mode="tree_summarize",
    embedding_mode="hybrid",
)
response = query_engine.query(question)
